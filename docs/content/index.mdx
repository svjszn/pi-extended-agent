Pi Extended Agent builds on [Pi](https://pi.dev) with project memory, planning,
permission controls, and a focused interface. Use the models and providers
supported by Pi.

## Installation

You need **Node.js 22.19 or later** and npm. On Windows, install Git for Windows
to provide Bash for Pi's shell tool. Install the package globally:

```sh
npm install -g --ignore-scripts pi-extended-agent
```

Pi is included in the package. If you already have a `pi` command installed,
follow [Already have Pi?](/getting-started/migration) first.

## Quick Start

Open a terminal in your project and start the agent:

```sh
cd your-project
pi
```

Inside Pi, run `/login` and follow the sign-in flow for your provider. Existing
credentials in your Pi profile are reused. Run `/model` to choose from the
models available to your account.

```text
/login
/model
```

Fresh sessions use Allow, which runs tools without this package's approval
prompts. For approval before changes and shell commands, switch to Ask:

```text
/permissions ask
```

You can now describe a task in the chat:

```text
Read this project and explain where the application starts.
```

## Choose a Model

Run `/model` to choose from the models available to your account. Use `/effort`
to change reasoning effort for models that support it.

```text
/model
/effort medium
```

Model selection and authentication are handled by Pi. See
[Models and effort](/guide/models) for selection shortcuts and defaults.

## Plan a Change

For a task you want to review before implementation, start a plan:

```text
/plan Add pagination to the search results
```

The agent researches the project and proposes steps. Open `/plan` to review
them, then run `/plan execute` when you want implementation to begin.
While planning, changes and shell commands are blocked.

See [Planning](/guide/planning) for editing, pausing, and resuming a plan.
