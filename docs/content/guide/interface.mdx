# Terminal Interface

The header shows the Pi engine version, current model, reasoning effort, and
working directory. The input stays below the conversation. Under it, you can
see the current mode and context usage.

An uncolored blank row separates user message cards from the following content;
compact tool calls remain grouped without extra gaps between calls. The terminal
tab stays titled **Pi Coding Agent**, including after agent tools finish. On
Windows, background update checks use a separate hidden console and Pi suppresses
the terminal/taskbar progress indicator. This does not change Windows Terminal
settings or the in-app Working indicator.

During a run, the status above the input shows elapsed time and generated output
tokens, for example `Working · 1m 23s · ↓ 3.2k tokens`. This includes the main
agent's reasoning, response text, and tool arguments across its model calls.
An estimate is marked with `~` while streaming if the provider has not reported
usage yet; reported output usage replaces that estimate when available.
The timer includes tool work and retries. Both counters reset for the next run.
Narrow terminals shorten or hide the details to keep the status and effort readable.

## Appearance

Use `/theme` and `/color` to choose interactively, or set them directly:

```text
/theme light
/color blue
```

Themes are `dark` and `light`. Accent choices are `default` (neutral), `yellow`,
`green`, `blue`, and `purple`. The accent colors the Pi mark, input borders,
activity charts, and subtle user message backgrounds. Text and effort colors
stay independent. Your choices are saved in the active profile.

In `/config` → **Preferences**, **Legacy logo** switches to the classic serif π.

## Tool Output

Choose **Tool output** in `/config` → **Preferences**. The choice is saved in the
active profile and applies to the terminal interface.

- **Compact** is the default. Consecutive successful reads and searches share a
  row such as `● Explored 4 files · 2 searches`. Click it to list the individual
  calls, then click a call to inspect its result. Opening a group keeps file
  contents collapsed. Running tools, errors, shell commands and file changes
  stay separate. Calls use labels such as `Bash(npm test)` and `Update(src/main.ts)`;
  a quiet `⎿` line shows the latest shell output or confirmed edit line counts.
- **Full** opens each tool's native details, including code, diffs and output.
  Syntax and diff colors remain visible in both themes.

Click a tool's header to expand or collapse it. Pi's tool-expansion shortcut
(`Ctrl+O` by default) expands or collapses all calls in the current conversation;
it does not change the saved preference.

These views change presentation only. The complete tool calls and results remain
in the session, and permissions and plan execution still require their ordinary
confirmations.

## Questions from the Agent

When a decision needs your input, the agent can open a question screen with the
`ask_user` tool. It can ask up to four questions together, with short descriptions,
recommended choices, multiple selection, or a written answer.

Use Up/Down to focus an option and Enter to continue. For multiple selection,
press Space or an option's number to toggle it. You can also click an option.
Start typing to write your own answer or add details to a selection. Tab and
Shift+Tab move between questions while keeping your answers. Review them and
press Enter on **Send answers** to return them to the agent. Escape cancels
without sending partial answers.

Questions work in auto, code, and plan modes, including Deny permissions.
Answering a question does not grant tool permissions or approve a plan; plan
execution still requires `/plan execute`. Questions share the dialog queue with
permission requests. Print/RPC clients report the screen as unavailable and
collect no answer. Subagents do not receive this tool.

## Resume a Chat

Run either command from your terminal:

```sh
pi -r
pi --resume
```

The resume screen lists recent chats with their names, dates, and message counts.
Type to search names or conversation text. Use Up/Down to select a chat and Enter
to continue it. Tab switches between the current project and all projects in the
active profile. Escape cancels. `/resume` opens the same screen inside Pi.

To reopen a specific chat without the picker, use `pi --resume SESSION_ID` or
`pi -r SESSION_ID`. The exit hint includes the current chat's ID. Without an ID,
both commands open the search screen. Use `--` before a follow-up prompt when
opening the picker, for example `pi -r -- "Continue the previous task"`.

For a phrase, search with quotes, such as `"login issue"`. `pi -c` or
`pi --continue` continues the most recent chat in the current project directly.

Resuming uses Pi's saved session, including its conversation history, model,
reasoning effort, permissions, and work mode.

## Keyboard Shortcuts

| Shortcut | Action |
| --- | --- |
| Shift+Tab | Cycle auto → plan → code → auto while idle |
| Shift+Left / Shift+Right | Decrease / increase reasoning effort |
| Ctrl+O | Expand or collapse tool details (default Pi binding) |
| Escape | Exit when the input is empty and the agent is idle |

During a run, Escape keeps Pi's cancellation behavior. If you have a draft or
autocomplete is open, Escape handles that state first.

Wait for the current run and queued messages to finish before switching modes.
Switching modes keeps your draft, permission choice, and effort.

## Command Screens

Enter a slash command such as `/status`, `/context`, or `/config` to open its
screen. Available actions are shown at the bottom.

- **Escape** closes a viewer or goes back.
- **Tab** changes sections in screens such as `/config`, `/memory`, and `/skills`.
- **Up/Down**, **Page Up/Down**, **Home/End**, and the mouse wheel scroll viewers.
- In text editors, **Enter** inserts a newline, **Ctrl+S** saves, and **Escape** cancels.

Opening an information screen does not send a request to a model.

## Account Usage

`/usage` shows available account limits and reset times for the active provider.
ChatGPT OAuth is supported. A Claude OAuth reader is also included, but has
not been verified with a live Claude account.

API keys and some providers do not expose account limits. When data is
unavailable, the screen says so; local token counts are not used to guess
your remaining allowance.

## Activity

`/stats` shows your local activity calendar, tokens, sessions, and streaks.
Use Tab or Left/Right to switch between All time, Last 7 days, and Last 30 days.

These statistics come from this profile's session history. They do not include
work on other computers or activity in the Codex app.
